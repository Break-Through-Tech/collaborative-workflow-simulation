# Git Practice: Collaborative Workflow

A practice repository for the **Collaborative Workflow Simulation** exercise.
Follow the step-by-step instructions on the course page.

## What's in here

- `evaluation.py`: metric functions for a binary classifier. You'll add `calculate_f1` here.
- `check.py`: run `python check.py` to test your function.
- `reflection.md`: answer the self-assessment questions here.

No extra libraries are needed. Plain Python 3 is enough.
